# Outer split indices
The four CSVs preserve `repeat`, zero-based `sample_index`, and `subset` from the supplied fixed outer-split files. The per-row `encoded_label` column was removed for this public source-code package. Row order and train/test assignments are unchanged; labels must be loaded from legitimately obtained input data. These indices are useful only with the **same original row ordering**. No patient-to-index mapping is distributed here.

The archived main trainer generates the five splits internally with `StratifiedShuffleSplit(n_splits=5, test_size=0.2, random_state=1)` and retains its generated train-row order. Baseline and revision loaders consume the stored split rows in their stored/sorted order. Identical split membership does **not** imply identical minibatch order or random-number use. Do not replace the main trainer with the revision trainer to assert bitwise reproduction.

These CSVs no longer have the original file hashes because one column was removed. Original and release hashes are both in `provenance/source_manifest.tsv`. They are index metadata, not evidence of label-independent upstream feature selection.
